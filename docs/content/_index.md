`gcpgrlx` turns a microservice spec into a repeatable `.grlx` deployment recipe for Google Cloud Run. The site explains the product, the CLI, and how it fits beside `grlx`.

The current release is **v0.3.0**, including Caddy rendering and apply flows, end-to-end smoke tests, worker and cron profiles, and reusable middleware presets for edge routing.
